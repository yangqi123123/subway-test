

#### 典型事件标注<font style="color:#DF2A3F;"></font>
##### 需求说明
典型事件标注用于在移动端对当前告警点位进行事件类型判定与归档。复核人员通过对比典型事件图库中的历史样本频谱，结合当前告警点频谱与历史时段/历史报警频谱，完成视觉比对与特征参考，最终将当前告警归类为指定事件类型，并可选择是否加入典型事件库。

##### 操作入口
| 入口 | 路径 | 说明 |
| --- | --- | --- |
| **主入口（推荐）** | 底部导航「巡检」→ 巡检记录 → 告警信息 → 告警详情 → 频谱图区域 → **「典型事件标注」** | 从当前告警上下文进入，自动携带告警参数 |
| **全景地图入口** | 全景地图 → 告警点 → 告警详情 → 频谱图 → **「典型事件标注」** | 与巡检记录入口逻辑一致 |


**URL 参数（由告警详情页传入）：**

| 说明 | 示例 |
| --- | --- |
| 告警编号 | `201` |
| 报警位置（区间 + 里程） | `马房山->街道口 Z25+610` |
| 关联项目名称 | `金融街六中北项目` |
| 报警时间 | `2024-6-23 08:14:49` |
| 来源标识 | `全时全域` |


##### 交互动作
+ **页面初始化**
1. 解析 URL 参数，生成当前点位标题（格式：`报警日期 区间 里程`，如 `2024-6-23 马房山->街道口 Z25+610`）。
2. 默认加载该分类下第一个典型事件。
3. 加载当前告警点频谱图（左侧频谱图）。
4. 右侧历史频谱图为空态，提示「点击「生成」或选择历史记录加载右侧频谱图」。
5. 「历史时段」模式下，日期默认取告警日期。
+ **事件分类**

| 动作 | 交互说明 |
| --- | --- |
| 切换分类 Tab | 点击「钻探 / 破拆 / 机械施工 / 降水」等标签，刷新典型事件图库与对比区 |
| 新增分类标签 | 点击「新增分类标签」→ 弹出模态框 → 输入名称（≤12 字）→ 保存 / 取消 |
| 关闭模态框 | 点击遮罩、取消按钮、× 或按 Esc |


**典型事件图库**

| 动作 | 交互说明 |
| --- | --- |
| 浏览频谱图缩略图 | 横向滑动查看当前分类下典型事件卡片 |
| 选中典型事件 | 点击卡片，高亮选中态，刷新「典型事件对比」区（频谱、照片、复核、备注） |


+ **典型事件对比 & 特征信息**
+ **典型事件对比：** 展示选中样本的频谱图、FBG 编号 / 区间 / 里程、现场照片、复核情况、备注（只读参考）。
+ **特征信息：** 展示「波形特征」「频谱特征」两张参考图（只读，来源后台知识库-特征信息上传）。

**当前点位频谱图（双图对比）**

**模式切换（Tab）：**

| 模式 | 界面变化 |
| --- | --- |
| **历史时段**（默认） | 显示日期、时间、时长选择 +「生成」按钮；下方为历史时段下拉选择 |
| **历史报警** | 隐藏生成栏；下方为历史报警卡片画廊（缩略频谱 + 日期） |


**历史时段模式：**

| 动作 | 交互说明 |
| --- | --- |
| 点击「生成」 | 按选定日期、时间、时长（30/60/120 分钟）生成右侧历史频谱图 |
| 选择历史时段 | 下拉选择已有记录，加载对应右侧频谱图 |


**历史报警模式：**

| 动作 | 交互说明 |
| --- | --- |
| 选择历史报警卡片 | 点击卡片，加载对应告警的历史频谱至右侧 |


**双图布局：**

+ 左：**当前告警点频谱图**（固定，来自当前告警，点击后弹窗预览大图）。
+ 右：**历史时段频谱图**（动态加载；未加载时显示空态提示）。

切换「历史时段 / 历史报警」模式时，清空右侧已加载频谱，需重新生成或选择。

+ **标注表单 & 提交**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 归类为 | 下拉单选 | 选项与事件分类一致，默认当前选中分类 |
| 加入典型事件 | 复选框 | 勾选后将当前标注样本纳入典型事件库，并存入后台知识库-典型事件管理和频谱图管理页面存档 |
| 备注 | 多行文本 | 补充说明，最多240个字符，选填 |


| 动作 | 交互说明 |
| --- | --- |
| 提交标注 | 点击底部「提交标注」，校验通过后提交，Toast 提示提交结果 |


##### 规则说明
| 数据项 | 来源系统 | 说明 |
| --- | --- | --- |
| 当前告警信息 | 后台告警信息-全时全域告警 | 通过 URL 参数传入：告警编号、位置、项目、时间 |
| 当前告警点频谱图 | 后台频谱图管理 | 对应当前告警点位的实时/已生成频谱 |
| 典型事件分类 | 后台典型事件标注管理 | 用户新增 |
| 典型事件图库 | 后台典型事件库 | 按分类存储的历史标注样本（FBG 编号、日期、区间、里程、频谱、照片、复核、备注） |
| 典型事件频谱图 | 后台频谱图管理 | 与典型事件样本绑定的频谱资源 |
| 特征信息（波形/频谱） | 后台典型事件特征库 | 后台知识库-特征信息管理上传 |
| 现场照片 | 告警复核记录 | 典型事件关联的历史复核现场照片 |
| 历史时段记录 | 后台频谱图管理 | 按日期时间窗口生成的历史频谱记录 |
| 历史报警记录 | 后台告警信息 | 同点位或相关点位的历史告警及其频谱 |
| 标注提交结果 | 后台典型事件标注服务 | 提交后，写入后台知识库-典型事件管理和频谱图管理页面存档。 |


##### 异常处理
| 异常场景 | 处理方式 |
| --- | --- |
| URL 参数缺失 | 生产环境应提示「缺少告警上下文」并引导返回 |
| 分类名称为空 | Toast：「请输入分类标签名称」，聚焦输入框 |
| 分类名称重复 | Toast：「分类标签名称已存在」，聚焦输入框 |
| 当前分类无典型事件 | 图库区展示「当前分类暂无典型事件」，对比区无样本数据 |
| 历史频谱未加载 | 右侧展示空态文案：「点击「生成」或选择历史记录加载右侧频谱图」 |
| 频谱图 / 特征图 / 现场照片加载失败 | 展示占位图或「加载失败，点击重试」；不影响其他区块操作 |
| 历史时段 / 历史报警接口无数据 | 下拉/画廊为空；提示「暂无历史记录」 |
| 网络异常导致提交失败 | Toast：「提交失败，请稍后重试」；保留表单已填内容，允许重新提交 |
| 告警已关闭 / 无标注权限 | 表单只读或隐藏提交按钮，提示「该告警已关闭，仅可查看」 |
| 重复提交 | 提交中按钮置灰防重复；成功后 Toast 提示并可选返回告警详情 |


##### 输出结果
| 输出项 | 说明 |
| --- | --- |
| **事件标注记录** | 包含告警编号、归类类型、备注、标注人、标注时间、是否加入典型事件 |
| **典型事件库条目**（勾选时） | 新增或更新典型事件样本：FBG 关联、分类、频谱、备注、来源告警 |
| **页面反馈** | Toast：「已提交"{归类类型}"标注」 |
