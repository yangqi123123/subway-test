#### 典型事件标注<font style="color:#DF2A3F;"></font>
##### 需求说明
移动端典型事件标注用于复核人员在告警现场对当前告警点位进行事件类型判定、频谱对比与归档。页面集成当前告警点频谱、历史/典型事件频谱对比、事件分类、典型事件图库、特征信息参考及标注提交能力，支持将当前告警样本纳入典型事件库。

##### 操作入口
| 入口 | 路径 | 说明 |
| --- | --- | --- |
| **主入口（推荐）** | 底部导航「巡检」→ 巡检记录 → 告警信息 → 告警详情 → **「典型事件标注」** | 从当前告警上下文进入，自动携带告警参数 |
| **全景地图入口** | 全景地图 → 告警点 → 告警详情 → **「典型事件标注」** | 与巡检记录入口逻辑一致 |


**URL 参数（由告警详情页传入）：**

| 说明 | 示例 |
| --- | --- |
| 告警编号 | `201` |
| 报警位置（区间 + 里程） | `中南医院站->湖北日报站 Z25+610` |
| 关联项目名称 | `武昌段排水改造工程` |
| 报警时间 | `2024-6-23 08:14:49` |


##### 页面布局与交互动作
+ **页面初始化**
1. 解析 URL 参数，生成当前点位标题（格式：`报警日期 区间 里程`，如 `2024-6-23 中南医院站->湖北日报站 Z25+610`）。
2. 默认选中首个事件分类（如「钻探」），并加载该分类下第一个典型事件作为参考。
3. 左侧自动加载当前告警点频谱图。
4. 右侧对比频谱图为空态，提示「点击「去生成对比频谱图」加载右侧频谱图」。
5. 默认展开「典型事件对比」区域。
6. 表单单选默认值：「归类于」默认当前分类，「加入典型事件」默认「是」，备注为空。

+ **顶部导航**

| 元素 | 交互说明 |
| --- | --- |
| 返回按钮 | 返回告警详情页；带 `fromGis=1` 参数 |
| 页面标题 | 「典型事件标注」 |


+ **典型事件对比区**

| 元素 | 交互说明 |
| --- | --- |
| 收起/展开 | 点击标题栏「收起/展开」按钮，切换对比区内容显隐；收起后只保留标题栏与生成按钮 |
| 当前告警点信息 | 显示 `报警日期 区间 里程`，由 URL 参数解析生成 |
| 去生成对比频谱图 | 点击打开底部「生成频谱图」弹窗；生成后按钮变为「重新生成」 |
| 当前告警点频谱图（左） | 固定显示当前告警点频谱；点击后进入全屏预览 |
| 对比频谱图（右） | 未生成时展示空态文案；生成后加载对应频谱；点击后进入全屏预览 |
| 对比详情 | 典型事件模式下展示：现场照片、复核情况、备注、特征信息（波形特征/频谱特征） |


+ **事件归类表单**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 归类于 | 下拉单选 | 选项来自事件分类列表；默认当前选中分类；切换时会同步切换分类 Tab 与典型事件图库 |
| 加入典型事件 | 下拉单选 | 选项：是 / 否；默认「是」。选择「是」时，当前标注样本纳入典型事件库 |
| 备注 | 多行文本 | 最多 240 个字符，实时显示字数统计 `0/240` |


+ **底部操作**

| 元素 | 交互说明 |
| --- | --- |
| 提交标注 | 点击后 Toast 提示「已提交“{归类类型}”标注」；提交中需防重复点击 |


##### 生成频谱图弹窗（底部弹出）
点击「去生成对比频谱图」后，从底部弹出全屏/半屏弹窗，提供四种生成方式 Tab：

| Tab | 内容 | 交互说明 |
| --- | --- | --- |
| **自定义时段** | 年月日、时间、时间间隔（30/60/120 分钟） | 填写后点击「生成」，按自定义时间窗口生成右侧对比频谱 |
| **历史时段** | 历史时段记录列表 | 选择一条历史时段记录，点击「生成」加载对应频谱 |
| **历史报警** | 历史报警卡片画廊（含缩略频谱、日期、告警编号、等级） | 选择一条历史报警记录，点击「生成」加载对应频谱；点击缩略图可预览 |
| **典型事件** | 事件分类 Tab + 典型事件图库 | 选择分类后，从图库中选择典型事件样本，点击「生成」加载该样本频谱；点击缩略图可预览 |

**弹窗通用规则：**
- 未选择有效内容时，「生成」按钮置灰（opacity 0.5）。
- 点击遮罩、关闭按钮、按 Esc 可关闭弹窗。
- 生成成功后自动关闭弹窗，右侧对比区加载频谱，若对比区处于收起状态则自动展开。


##### 频谱图预览弹窗
点击任意频谱图（当前告警点、对比频谱、典型事件图库、历史报警卡片）进入全屏预览：

| 元素 | 交互说明 |
| --- | --- |
| 标题 | 显示当前频谱名称 |
| 图片区 | 居中展示频谱大图 |
| 左右切换 | 点击左右箭头或按键盘 ←/→ 切换同组频谱；首张/末张自动禁用对应箭头 |
| 计数器 | 显示 `当前索引 / 总数量` |
| 关闭 | 点击关闭按钮、遮罩或按 Esc 退出预览 |


##### 新增分类标签弹窗
通过「更多参考信息」区或「典型事件」生成面板中的「新增」按钮打开：

| 元素 | 交互说明 |
| --- | --- |
| 分类标签名称 | 输入框，最多 12 个字符 |
| 保存 | 校验非空、不重复后新增分类；新增后自动切换到该分类并刷新相关图库与下拉选项 |
| 取消/关闭 | 关闭弹窗，不保存 |


##### 更多参考信息（默认折叠）
页面保留完整参考信息面板，默认隐藏，可通过外部入口或调试展开：

| 模块 | 说明 |
| --- | --- |
| 事件分类 | 横向分类 Tab（钻探/破拆/机械施工/降水等），支持新增分类标签 |
| 典型事件图库 | 当前分类下典型事件卡片横向列表；点击卡片高亮并刷新参考频谱与详情 |
| 典型事件对比 | 展示选中样本的参考频谱图、FBG 编号/区间/里程、现场照片、复核情况、备注 |
| 特征信息 | 展示「波形特征」「频谱特征」两张参考图 |
| 当前点位频谱图 | 支持「历史时段 / 历史报警」模式切换；历史时段模式下可自定义日期时间并生成；历史报警模式下展示历史报警卡片画廊 |


##### 规则说明
| 数据项 | 来源系统 | 说明 |
| --- | --- | --- |
| 当前告警信息 | 后台告警信息-全时全域告警 | 通过 URL 参数传入：告警编号、位置、项目、时间 |
| 当前告警点频谱图 | 后台频谱图管理 | 对应当前告警点位的实时/已生成频谱 |
| 事件分类 | 后台典型事件标注管理 | 预置：钻探、破拆、机械施工、降水；支持用户新增 |
| 典型事件图库 | 后台典型事件库 | 按分类存储的历史标注样本：FBG 编号、日期、区间、里程、频谱、照片、复核、备注 |
| 特征信息 | 后台典型事件特征库 | 波形特征、频谱特征参考图 |
| 历史时段记录 | 后台频谱图管理 | 按日期时间窗口生成的历史频谱记录 |
| 历史报警记录 | 后台告警信息 | 同点位或相关点位的历史告警及其频谱 |
| 标注提交结果 | 后台典型事件标注服务 | 提交后写入后台知识库-典型事件管理和频谱图管理页面存档 |
| 典型事件库条目（加入典型事件=是时） | 后台典型事件库 | 新增样本：告警编号、分类、频谱、备注、来源告警 |


##### 异常处理
| 异常场景 | 处理方式 |
| --- | --- |
| URL 参数缺失 | 生产环境提示「缺少告警上下文」并引导返回告警列表 |
| 分类名称为空 | Toast：「请输入分类标签名称」，聚焦输入框 |
| 分类名称重复 | Toast：「分类标签名称已存在」，聚焦输入框 |
| 当前分类无典型事件 | 图库区展示「当前分类暂无典型事件」，对比区无样本数据 |
| 历史频谱未加载 | 右侧展示空态文案：「点击「去生成对比频谱图」加载右侧频谱图」 |
| 频谱图 / 特征图 / 现场照片加载失败 | 展示占位图或「加载失败，点击重试」；不影响其他区块操作 |
| 历史时段 / 历史报警接口无数据 | 下拉/画廊为空；提示「暂无历史记录」 |
| 网络异常导致提交失败 | Toast：「提交失败，请稍后重试」；保留表单已填内容，允许重新提交 |
| 告警已关闭 / 无标注权限 | 表单只读或隐藏提交按钮，提示「该告警已关闭，仅可查看」 |
| 重复提交 | 提交中按钮置灰防重复；成功后 Toast 提示并可选返回告警详情 |
| 未选择生成来源 | 「生成」按钮置灰，提示用户先选择历史时段/报警/典型事件 |


##### 输出结果
| 输出项 | 说明 |
| --- | --- |
| **事件标注记录** | 包含告警编号、归类类型、备注、标注人、标注时间、是否加入典型事件 |
| **典型事件库条目**（加入典型事件=是时） | 新增或更新典型事件样本：FBG 关联、分类、频谱、备注、来源告警 |
| **页面反馈** | Toast：「已提交“{归类类型}”标注」 |
