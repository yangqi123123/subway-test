# 武汉地铁保护区管理平台小程序端 PRD-V1.0

## 系统概述
小程序端面向现场巡查、项目协同、告警复核、应急处置、无人机作业和管理查看场景，提供移动端地图、巡检、资产、数据统计、个人待办等能力。小程序端与管理后台共享用户权限、线路站点、项目、巡查、告警、无人机、应急资源、统计报表等数据。

## 产品形态
| 形态 | 说明 |
| --- | --- |
| 微信小程序 | 面向现场移动作业，支持定位、拍照、上传、查看、复核、待办处理。 |
| 后台联动 | 小程序提交和查看的数据均与后台对应业务模块联动。 |

## 角色说明
| 角色 | 职责 | 小程序端权限 |
| --- | --- | --- |
| 现场巡查员 | 执行巡检、上报照片视频、处理巡查任务 | 巡检记录新增、编辑、查看本人任务 |
| 告警复核人员 | 查看告警、补充复核情况、上传现场资料 | 告警详情、复核提交、频谱图查看 |
| 无人机飞手 | 查看无人机计划、设备、航线、日志 | 飞行计划查看、设备状态查看、日志报告查看 |
| 应急人员 | 查看应急人员、仓库、预案和物资 | 电话联系、地图导航、资源详情查看 |
| 管理人员 | 移动端查看项目、统计、待办和通知 | 统计查看、待办处理、详情查看 |

## 全局规则
1. 小程序端菜单层级必须严格按照“小程序菜单层级总览”执行。
2. 所有列表、详情、按钮按后台角色权限控制，无权限不展示或仅只读。
3. 用户、部门、线路、站点、区间、项目、机场、无人机、字典等基础数据来源于管理后台。
4. 小程序端采集数据需同步至后台对应业务模块。
5. 涉及定位、拍照、文件上传、电话、消息订阅时，调用微信小程序原生能力并处理授权异常。
6. 所有新增、编辑、提交、审批、确认、拒绝动作必须做必填校验、重复提交拦截和异常提示。

# 功能模块需求

## 1. 登录与身份校验
### 需求说明
用户通过账号密码或微信授权登录小程序，系统校验身份后进入首页，并按角色加载菜单与数据权限。
### 操作入口
小程序启动页 -> 登录页。
### 交互动作
1. 输入账号、密码后点击登录。
2. 选择微信授权登录时获取手机号并匹配后台用户。
3. 首次登录提示隐私协议和定位授权说明。
4. 登录成功进入默认首页。
### 规则说明（需注明数据来源）
- 用户账号、密码、手机号、状态、角色来源于后台系统管理。
- 角色菜单来源于后台角色管理和菜单权限。
- 停用用户、无移动端权限用户禁止登录。
### 异常处理
- 账号密码错误提示“账号或密码错误”。
- 用户停用提示“当前账号已停用”。
- 网络异常提示“网络异常，请稍后重试”。
### 输出结果
生成登录态，缓存用户信息、token、权限菜单和基础字典。
### 字段说明
| 字段名称 | 类型 | 必填 | 默认值 | 取值范围 |
| --- | --- | --- | --- | --- |
| 账号 | 文本 | 是 | 空 | 后台用户账号 |
| 密码 | 密码 | 是 | 空 | 6-32位 |
| 手机号 | 文本 | 条件必填 | 微信授权返回 | 11位手机号 |
| 登录方式 | 枚举 | 是 | 账号密码 | 账号密码/微信授权 |
| 隐私协议确认 | 布尔 | 是 | 否 | 是/否 |

## 2. 全景地图
### 需求说明
用户查看武汉地铁保护区移动 GIS 地图，展示线路、站点、项目、人员、告警、机场、无人机、应急资源和巡查区域。
### 操作入口
底部导航“全景地图”。
### 交互动作
1. 地图默认定位武汉。
2. 点击图层按钮展开图层控制。
3. 切换站点、项目、人员、告警点、机场、无人机、应急资源、巡查区域图层。
4. 点击地图图标显示详情卡片。
5. 在详情中执行查看详情、导航、拨打电话等动作。
### 规则说明（需注明数据来源）
- 底图来源于系统统一 GIS 地图服务。
- 线路、站点、区间来源于后台资产管理。
- 项目来源于后台项目管理和完工项目。
- 告警来源于后台告警信息和 AI 识别。
- 机场、无人机来源于后台机场设备管理和无人机设备管理。
- 应急资源来源于后台应急管理。
### 异常处理
- 定位失败提示授权定位。
- 点位无数据时展示“暂无详情”。
- 地图服务异常时展示重试。
### 输出结果
展示当前权限范围内地图图层和点位详情。
### 字段说明
| 字段名称 | 类型 | 必填 | 默认值 | 取值范围 |
| --- | --- | --- | --- | --- |
| 图层类型 | 枚举 | 是 | 站点 | 站点/项目/人员/告警/机场/无人机/应急资源/巡查区域 |
| 点位名称 | 文本 | 是 | 空 | 后台点位名称 |
| 经度 | 数字 | 是 | 空 | 合法经度 |
| 纬度 | 数字 | 是 | 空 | 合法纬度 |
| 点位状态 | 枚举 | 否 | 正常 | 正常/告警/离线/已巡查/待巡查 |
