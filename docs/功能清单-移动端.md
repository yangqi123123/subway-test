# 武汉地铁保护区管理平台 — 移动端功能清单

| 说明 | 内容 |
|------|------|
| 范围 | 移动端（微信小程序形态原型，`app/` 目录） |
| 层级约定 | **一级模块**：底部 Tabbar / 系统入口；**二级模块**：模块内菜单组或独立页面；**功能点**：页面级功能 |

## 附：通用能力

- **独立搜索页**：病害/夜班/人工/无人机/项目/打分/轨迹/待办/通知/已处理等列表均配独立搜索页（`*-search.html`），关键字搜索后结果回跳。
- **通用骨架**：列表页统一为「统计卡片 + 搜索条 + 筛选抽屉 + 卡片列表 + 详情视图 + 表单视图 + 删除确认 + 底部选择器弹层」结构。
- **上传能力**：资料（PDF/Word/Excel/ZIP ≤50MB）、照片（≤9 张 ≤20MB）、视频（≤9 个 ≤200MB），支持在线预览。
- **操作记录**：业务单据均记录操作时间轴（新增/确认/拒绝等），可弹窗查看。
