# 功能需求说明（设备信息 / 设备领用 / 巡查打分标准）

> 适用范围：管理后台（我的工作台 → 智慧巡检 → 巡查质量）

---

## 1. 设备信息

### 1.1 需求说明

管理后台设备信息页面提供人员轨迹定位设备的全生命周期管理能力，支持设备台账列表查询、新增、编辑、详情查看、导入、导出，并可按设备查看领用记录；设备数据与设备领用功能联动，已绑定人员的设备不允许直接删除。

### 1.2 操作入口

我的工作台 → 智慧巡检 → 巡查质量 → 设备信息；或从 人员轨迹/设备领用/统计分析/巡查打分 页面右侧快捷操作面板进入。

### 1.3 交互动作

1. 设备列表：支持查询全部设备数据；页面顶部配置统计卡片，右侧快捷筛选面板可按条件过滤列表；
2. 新增/编辑设备：录入设备IMEI、设备型号、设备名称、颜色、产地、厂家、备注，支持上传 1 张设备照片（点击或拖拽，可预览、可移除）；编辑时全字段回显；
3. 详情：以只读弹窗展示设备全部字段及照片；
4. 领用记录：列表操作列点击【领用记录】，弹窗以表格展示该设备的历史领用记录，并支持再次筛选；
5. 删除：二次确认提示"当前设备已绑定人员，请解绑后删除"；
6. 导入设备：弹窗上传 .xlsx/.xls 文件（点击或拖拽），提供【下载模板】，模板真实下载；
7. 导出：按当前筛选结果导出 Excel 文件。

### 1.4 规则说明

- 数据来源：设备台账数据来自设备信息页面新增/导入；领用记录数据来自设备领用功能产生的绑定/解绑记录；列表数据随快捷筛选实时联动；
- 顶部统计卡片口径：
  1. 设备总数：当前列表内设备总台数；
  2. 在线设备：最后在线时间为数据中最新在线日期的设备台数；
  3. 离线设备：设备总数 − 在线设备数；
  4. 已绑定人员：当前已与人员绑定的设备台数。

### 1.5 异常处理

1. 新增/编辑时设备IMEI、设备型号为空，提示"请完善必填项：设备IMEI、设备型号"，不允许提交；
2. 导入仅支持 .xlsx/.xls 格式，选择或拖拽其它格式文件时提示"仅支持上传 .xlsx、.xls 格式文件"并拒绝接收；
3. 删除已绑定人员的设备时给出解绑提示，引导先解绑再删除；
4. 上传照片仅支持图片格式（JPG/PNG/WEBP），非图片文件不予接收；
5. 领用记录为空时展示"暂无领用记录"。

### 1.6 输出结果

1. 支持新增、修改、删除设备台账，列表与统计卡片实时刷新；
2. 导出"设备信息导出.xls"，表头：设备IMEI、设备型号、设备名称、颜色、产地、厂家、最后在线时间、备注、创建时间；
3. 下载模板输出"设备导入模板.xls"，表头：设备IMEI（必填）、设备型号（必填）、设备名称、颜色、产地、厂家、备注。

### 1.7 字段说明

| 字段名称 | 类型 | 必填 | 默认值 | 取值范围 |
| --- | --- | --- | --- | --- |
| 设备IMEI | 文本 | 是 | 空 | 手工录入或模板导入，15 位设备串号 |
| 设备型号 | 文本 | 是 | 空 | 手工录入或模板导入 |
| 设备名称 | 文本 | 否 | 空 | 手工录入 |
| 颜色 | 文本 | 否 | 空 | 手工录入 |
| 产地 | 文本 | 否 | 空 | 手工录入 |
| 厂家 | 文本 | 否 | 空 | 手工录入 |
| 备注 | 多行文本 | 否 | 空 | 手工录入 |
| 上传照片 | 图片文件 | 否 | 空 | JPG/PNG/WEBP，限 1 张 |
| 最后在线时间 | 日期时间 | 只读 | 空 | 设备上报回传 |
| 创建时间 | 日期时间 | 只读 | 自动生成 | 系统生成 |
| 领用记录筛选-设备IMEI/设备型号/用户名称 | 文本 | 否 | 空 | 模糊匹配 |
| 领用记录筛选-领用开始时间/领用结束时间 | 日期 | 否 | 空 | 按记录的领用起止日期过滤 |

## 2. 设备领用

### 2.1 需求说明

管理后台设备领用页面用于将人员与定位设备进行绑定/解绑管理，支持单条绑定/解绑、批量绑定、批量解绑、导入、导出；绑定关系与人员轨迹功能联动，作为人员轨迹定位数据的设备来源。

### 2.2 操作入口

我的工作台 → 智慧巡检 → 巡查质量 → 设备领用；或从 人员轨迹/设备信息/统计分析/巡查打分 页面右侧快捷操作面板进入。

### 2.3 交互动作

1. 领用列表：支持查询全部领用记录；页面顶部配置统计卡片，右侧快捷筛选面板可按设备IMEI、设备型号、用户名称、所属线路、起始区间、终点区间过滤；
2. 绑定：未绑定记录点击【绑定】打开绑定人员弹窗，设备IMEI、设备型号只读回显；选择所属线路后起始/终点区间联动，绑定人员按线路+区间过滤，选中后手机号码、所属部门自动回显；可填写领用开始/结束时间；
3. 批量绑定：勾选多台未绑定设备，弹窗以表格逐行展示设备IMEI，每行用搜索选择组件选择绑定人员，行可删除；
4. 解绑：已绑定记录点击【解绑】，二次确认"确认将设备（IMEI）与某某解绑吗？"；批量解绑二次确认"确认解绑选中的 N 台设备吗？"；
5. 详情：只读弹窗展示领用记录全部字段；
6. 删除：未绑定记录显示【删除】，二次确认"确认删除当前领用记录吗？"；已绑定记录隐藏删除按钮；
7. 导入/导出：同设备信息页规则。

### 2.4 规则说明

- 数据来源：设备数据来自设备信息台账；人员、手机号码、所属部门来自用户管理；线路与区间站点来自线路区间基础台账；绑定/解绑结果回写领用记录并同步至设备领用状态；
- 顶部统计卡片口径：
  1. 设备总数：当前列表内领用记录总台数；
  2. 已绑定：状态为已绑定的设备台数；
  3. 未绑定：设备总数 − 已绑定数；
  4. 在线设备：最后在线时间为数据中最新在线日期的设备台数。

### 2.5 异常处理

1. 绑定时所属线路、起始区间、终点区间、绑定人员为必填，缺失时给出对应提示，不允许提交；
2. 起始区间与终点区间相同，提示"起始区间与终点区间不能相同"；
3. 领用结束时间早于开始时间，提示"领用结束时间不能早于领用开始时间"；
4. 批量绑定未勾选设备、或勾选中含已绑定设备时给出提示；批量解绑同理拦截含未绑定设备的情况；
5. 批量绑定弹窗中存在未选择人员的行时，提示具体设备IMEI，不允许提交；
6. 所选线路/区间下无匹配人员时，绑定人员下拉显示"暂无匹配人员"；
7. 导入文件格式非 .xlsx/.xls 时拒绝接收并提示；
8. 已绑定设备不提供删除入口，防止误删绑定关系。

### 2.6 输出结果

1. 绑定/解绑/删除后列表、状态标签与统计卡片实时刷新；绑定结果同步作为人员轨迹的定位设备来源；
2. 导出"设备领用导出.xls"，表头：用户名称、所属线路、所属区间、设备IMEI、设备型号、设备名称、状态、最后在线时间；
3. 下载模板输出"设备领用导入模板.xls"，表头：用户名称、所属线路、所属区间、设备IMEI、设备型号、设备名称。

### 2.7 字段说明

| 字段名称 | 类型 | 必填 | 默认值 | 取值范围 |
| --- | --- | --- | --- | --- |
| 用户名称 | 搜索选择 | 绑定时必填 | 空 | 按所属线路+区间过滤后的用户 |
| 所属线路 | 下拉 | 绑定时必填 | 空 | 线路基础台账 |
| 起始区间 | 下拉 | 绑定时必填 | 空 | 随所属线路联动，且不可与终点区间相同 |
| 终点区间 | 下拉 | 绑定时必填 | 空 | 随所属线路联动，且不可与起始区间相同 |
| 手机号码 | 文本 | 只读 | 空 | 随绑定人员自动回显 |
| 所属部门 | 文本 | 只读 | 空 | 随绑定人员自动回显 |
| 领用开始时间 | 日期时间 | 否 | 当前时间 | 手工选择 |
| 领用结束时间 | 日期时间 | 否 | 空 | 不得早于领用开始时间 |
| 设备IMEI | 文本 | 只读 | 自动 | 设备台账带入 |
| 设备型号 | 文本 | 只读 | 自动 | 设备台账带入 |
| 设备名称 | 文本 | 只读 | 自动 | 设备台账带入 |
| 状态 | 标签 | 只读 | 未绑定 | 已绑定/未绑定，随绑定解绑动作切换 |
| 最后在线时间 | 日期时间 | 只读 | 空 | 设备上报回传 |
| 绑定时间 | 日期时间 | 只读 | 自动生成 | 绑定动作触发时写入 |

## 3. 巡查打分标准

### 3.1 需求说明

管理后台巡查打分标准页面用于按"线路-区间"维护巡查评分规则，支持按区间分别设置巡查最低时间与 6 档评分标准（A~F 档），保存后系统按此规则自动计算对应区间的巡查得分；同一规则支持复制并批量粘贴至其他区间。

### 3.2 操作入口

我的工作台 → 智慧巡检 → 巡查质量 → 巡查打分标准；或从 人员轨迹/设备信息/设备领用/统计分析/巡查打分 页面右侧快捷操作面板进入。

### 3.3 交互动作

1. 区间选择：左侧线路区间树按线路分组展示全部区间，顶部搜索框可按线路或区间名称过滤；点击区间右侧加载该区间的评分规则；
2. 规则编辑：设置巡查最低时间（分钟）与 5 个超出保护区时间阈值，各档位表达式随输入实时更新；相邻档位共享的阈值输入框改动时自动联动同步；
3. 保存：校验通过后保存当前区间规则，提示"巡查打分标准已保存"；
4. 取消：放弃当前编辑内容，恢复为该区间已保存的规则；
5. 复制/粘贴：点击【复制】复制当前区间规则并提示"已复制某某区间的巡查打分标准，可点击其他区间进行粘贴"；切换至其他区间后显示【粘贴】按钮，点击后规则写入当前区间；粘贴按钮在复制来源区间自动隐藏，支持连续粘贴至多区间批量应用。

### 3.4 规则说明

- 数据来源：线路与区间树来自线路区间基础台账；评分规则按区间独立维护、独立保存，互不影响；保存后的规则作为巡查打分功能计算区间得分的依据；
- 评分档位口径（T=巡查最低时间，B=超出保护区时间，t0~t4 为 5 个阈值，默认 0/5/8/11/14，区间均为左开右闭）：
  1. A档 100 分：巡查时间 ≥ T，且 B ≤ t0；
  2. B档 90 分：巡查时间 ≥ T，且 t0 < B ≤ t1；
  3. C档 80 分：巡查时间 ≥ T，且 t1 < B ≤ t2；
  4. D档 70 分：巡查时间 ≥ T，且 t2 < B ≤ t3；
  5. E档 60 分：巡查时间 ≥ T，且 t3 < B ≤ t4；
  6. F档 <60 分：巡查时间 < T，或 B > t4；
- 顶部统计卡片口径：本页面为规则配置页，无统计卡片。

### 3.5 异常处理

1. 巡查最低时间须为正整数，否则对应输入框实时标红并提示"巡查最低时间请输入正整数"；
2. 阈值须为 ≥0 的整数，否则对应输入框实时标红并提示"超出保护区时间范围请输入数字"；
3. 5 个阈值须严格递增（t0<t1<t2<t3<t4），否则相邻冲突输入框实时标红并提示"时间范围需逐级递增"；存在校验错误时不允许保存、不允许复制；
4. 区间树搜索无匹配时展示"无匹配区间"。

### 3.6 输出结果

1. 各区间评分规则保存生效，作为巡查打分自动计算的依据；
2. 复制/粘贴完成规则的跨区间批量应用，粘贴后即时写入目标区间并可继续粘贴至其他区间。

### 3.7 字段说明

| 字段名称 | 类型 | 必填 | 默认值 | 取值范围 |
| --- | --- | --- | --- | --- |
| 区间名称 | 文本 | 只读 | 自动 | 左侧区间树选中区间带入 |
| 巡查最低时间 T | 数字 | 是 | 22 | 正整数，单位分钟 |
| 阈值 t0 | 数字 | 是 | 0 | ≥0 整数，且小于 t1 |
| 阈值 t1 | 数字 | 是 | 5 | ≥0 整数，且大于 t0、小于 t2 |
| 阈值 t2 | 数字 | 是 | 8 | ≥0 整数，且大于 t1、小于 t3 |
| 阈值 t3 | 数字 | 是 | 11 | ≥0 整数，且大于 t2、小于 t4 |
| 阈值 t4 | 数字 | 是 | 14 | ≥0 整数，且大于 t3 |
| 档位标签 | 文本 | 只读 | A~F | 随阈值与最低时间动态生成表达式文案 |
